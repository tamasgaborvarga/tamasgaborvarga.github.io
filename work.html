New website concept for Kertvéllesy Architects

Architecture studio · Pécs

Starting point

  • 58-page WordPress site (WPML, Visual Composer, Slider Revolution)
  • Phone numbers not tappable on any page; pinch-zoom disabled on phones
  • No page descriptions for Google, no share image, no structured company data

What I built

  • 60-page static site generated by a Python build from the original content
  • 243 project images converted to responsive WebP
  • Editorial look with its own type pairing, full-screen menu, filterable project archive
  • Animated logo intro, light/dark theme, tap-to-call everywhere

New website concept for ALCUFER

Industrial waste & metal recycling · Győr · 20 sites

Starting point

  • No mobile layout — phones got the desktop page scaled down from 1240 px
  • Page title in Google: “Magyar — Alcufer Kft.”; no H1, page descriptions or share image
  • Logo available only as a 254×74 px raster image

What I built

  • New identity: vector logo in 16 variants, copper–steel–aluminium palette with material colour codes

  • Unique titles, descriptions and structured data on every page
